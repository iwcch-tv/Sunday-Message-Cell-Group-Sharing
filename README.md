# 일원중앙교회 소그룹 나눔 사이트

주일 설교를 중심으로 소그룹 나눔을 준비하는 다섯 페이지 사이트입니다.
현재 베드로전서 1장 13&ndash;16절, "생각이 바뀌지 않으면 삶도 바뀌지 않습니다" 설교로 첫 주차 내용이 채워져 있습니다.
각 페이지의 날짜 자리([날짜])만 채우신 뒤 그대로 첫 배포에 사용하시면 됩니다.

## 폴더 구성

```
index.html               메인 페이지 (이번 주 안내 · 차례)
sermon.html               1. 설교원고
summary-images.html       2. 말씀요약 이미지
meditation-images.html    3. 노트북LM 묵상 이미지
discussion.html           4. 소그룹 나눔 질문 (3C)
about.html                 5. 교회 소개 및 소식
style.css                  공통 스타일
images/summary/            말씀요약 이미지 파일을 넣는 곳
images/meditation/         노트북LM 묵상 이미지 파일을 넣는 곳
```

## 처음 배포하는 방법

1. 깃허브에 새 저장소를 만듭니다. (예: `iwcch-tv/cell-group-sharing`)
2. 이 폴더 전체를 저장소에 업로드합니다. 깃허브 웹사이트의 "Add file → Upload files" 기능을 사용하면 터미널 없이도 폴더 안의 파일을 끌어다 놓는 방식으로 올릴 수 있습니다.
3. 저장소의 Settings → Pages 메뉴에서 Branch를 `main`, 폴더를 `/(root)`로 지정하고 저장합니다.
4. 몇 분 뒤 `https://[계정명].github.io/[저장소명]/` 주소로 사이트가 공개됩니다.

## 매주 업데이트하는 방법

**설교원고**
`sermon.html`을 열어 `[이번 주 설교 제목]`으로 표시된 부분과, 본문 하단의 안내 문구(placeholder 영역)를 그 주의 설교 원고로 바꿉니다.

**말씀요약 · 묵상이미지**
해당 이미지 파일을 `images/summary` 또는 `images/meditation` 폴더에 올린 뒤, 각 페이지의 주석으로 표시된 형식을 참고해 `<figure>` 항목을 추가합니다.

**나눔질문**
`discussion.html`의 세 단계(상황·도전·변화) 아래 대괄호로 표시된 질문 자리를 그 주 설교 내용에 맞는 질문으로 바꿉니다.

**교회소식**
`about.html`의 "이번 주 소식" 목록을 그 주 공지 사항으로 바꿉니다.

**메인 페이지**
`index.html`의 제목과 본문 말씀, 날짜만 그 주 내용으로 바꾸면 나머지 차례는 그대로 유지됩니다.

원고와 이미지를 전달해 주시면 위 다섯 파일의 내용을 채운 상태로 매주 다시 정리해 드릴 수 있습니다.
